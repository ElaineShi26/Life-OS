# Life OS

个人生活操作系统。单文件网页应用，零依赖、零后端、零追踪 —— 所有数据只存在你浏览器本地。

**线上地址**：https://elaineshi26.github.io/Life-OS/

## 六个板块

| | 板块 | 解决的问题 |
|---|---|---|
| 01 | 决策 | 留下「当时为什么这么选」，半年后能验对错 |
| 02 | 监控 | 只放变了就必须改计划的指标 |
| 03 | 周计划 | 这周只推三件事，多的拦掉 |
| 04 | 执行 | 今天落地什么动作 |
| 05 | 记录 | 发生了什么，作为复盘证据 |
| 06 | 复盘 | 把这一周变成判断：哪条假设被证据推翻了 |

链条是闭环的：决策 → 周计划 → 执行 → 监控 → 记录 → 复盘 → 回到决策。

## 数据

存在浏览器 `localStorage`，**绑定访问地址**。不同地址（本地 `file://`、局域网 IP、GitHub Pages）是三个独立的数据仓。

换地址前：先在旧地址「导出」JSON，到新地址再「导入」。

## 本地开发

直接用浏览器打开 `index.html` 即可，无需构建、无需服务器。

## 更新

改完 `index.html` 后推送：

```bash
git add -A && git commit -m "描述这次改动" && git push
```

GitHub Pages 约 1 分钟后自动生效。部署密钥只对这一个仓库有写权限。
